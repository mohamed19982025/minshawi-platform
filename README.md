# المصحف الثاني للشيخ محمد صديق المنشاوي

هذا المشروع عبارة عن منصة ويب حديثة مبنية لنشر التسجيلات النادرة للمصحف الثاني للشيخ القارئ محمد صديق المنشاوي، بتصميم إسلامي متميز ودعم كامل للوضع الليلي وواجهة تدعم اللغة العربية بالكامل.

## التقنيات المستخدمة
- **Next.js 15 (App Router)**
- **TypeScript**
- **Tailwind CSS v4**
- **Prisma + SQLite**
- **NextAuth.js** مع **Argon2id** لتشفير كلمات المرور
- **Zod & React Hook Form**
- **Lucide React** (أيقونات)

## الميزات
- مشغل صوتي احترافي يدعم استكمال التشغيل، تقديم/تأخير، التحكم بالسرعة وتوافق كامل مع الجوال.
- بحث فوري وسريع بين السور المتاحة.
- لوحة إدارة للتحكم بالسور (إضافة، تعديل، حذف) مع إمكانية رفع الملفات الصوتية.
- إعدادات لتحديث الشعار وصورة المشاركة (OpenGraph).
- حماية أمنية شاملة (CSRF, Rate Limiting, CSP, HSTS).
- SEO متقدم متضمن Sitemap, Robots, Metadata, OpenGraph.

## التشغيل المحلي
```bash
npm install
npm run dev
```
